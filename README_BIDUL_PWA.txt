BIDUL 오프라인 홈 화면 웹 앱 배포 안내

[배포 파일]
- index.html
- sw.js
- manifest.json
- pwa-icon-192.png
- pwa-icon-512.png

[GitHub Pages에 올리는 방법]
1. ZIP 안의 파일 5개를 현재 사이트의 index.html이 있는 폴더에 함께 올립니다.
2. 기존 index.html은 이 버전으로 교체하고, 나머지 기존 파일은 삭제하지 않습니다.
3. 사이트 화면의 BIDUL 로고에 기존 icon.png를 사용하고 있었다면 그 파일도 그대로 유지합니다.
4. 변경 사항을 GitHub에 반영하고 Pages 배포가 완료된 뒤 HTTPS 주소로 접속합니다.

[홈 화면에 추가하고 오프라인 확인하기]
1. iPhone/iPad의 Safari에서 배포된 BIDUL 주소를 온라인 상태로 엽니다.
2. 공유 메뉴에서 '홈 화면에 추가'를 선택합니다.
3. '웹 앱으로 열기(Open as Web App)' 옵션을 켠 상태로 추가합니다.
4. 설치 후 홈 화면의 BIDUL을 인터넷이 연결된 상태에서 한 번 실행해 오프라인 캐시가 준비되게 합니다.
5. 그다음 Wi-Fi와 셀룰러 데이터를 끄고 홈 화면의 BIDUL을 다시 실행해 확인합니다.

[오프라인 동작 범위]
- BIDUL의 HTML/CSS/내장 JavaScript와 PWA 아이콘을 캐시합니다.
- 일반 글과 비밀 글, 이미지 및 직접 업로드한 영상은 앱의 IndexedDB에 저장된 자료라면 오프라인에서도 읽을 수 있습니다.
- YouTube 임베드 및 외부 웹사이트 링크의 콘텐츠는 인터넷이 없으면 재생/접속되지 않습니다.
- 최초 방문 및 서비스 워커 캐시 준비 전에는 오프라인으로 처음 실행할 수 없습니다.

[기존 Safari 데이터 관련 중요 주의]
iOS 홈 화면 웹 앱은 Safari 탭과 별도의 저장 공간(IndexedDB/Cache Storage)을 사용합니다. 따라서 Safari에서 기존 BIDUL에 저장했던 데이터가 설치한 홈 화면 앱으로 자동 복사된다고 가정하면 안 됩니다. 기존 Safari 데이터를 삭제하지 마세요.
현재 BIDUL의 '캐시 내보내기' 기능은 일반 글 목록만 내보내므로, 비밀 글과 저장 영상까지 완전하게 이전하는 백업 수단은 아닙니다. 기존 데이터 이전이 필요하면 먼저 전체 백업/복원 기능을 별도로 마련해야 합니다.
